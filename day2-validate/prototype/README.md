# Prototype: ServiceSG enquiry inbox

Scenario A · ServiceSG enquiry response.

All enquiries in this prototype are made up. No real residents, names, NRICs or policy pages.

## What is built so far

Screen 1 only: the inbox list. It shows 6 made-up enquiries, each with a status.

Not built yet: the enquiry view, citations, and the Approve, Edit and Restore original buttons.

## How to open it

Open `index.html` in a web browser. No server and no install.

## Files

- `index.html`: the page.
- `style.css`: how it looks.
- `app.js`: draws the inbox list.
- `data/enquiries.js`: the made-up enquiries and status labels.

## Nothing is sent

The page makes no network calls and sends nothing.
